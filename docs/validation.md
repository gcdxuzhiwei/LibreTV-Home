- Gradle 官方发行包 SHA256 已核验并固定在 Wrapper 配置中。

## 接口与解析

使用项目的真实 `Catalog.java` 编译运行临时 Java 验证程序：

- 网页线路过滤、多线路与分集解析、带查询参数的媒体 URL、影片存储序列化往返验证通过。
- 非凡、量子、暴风：直接请求列表、下一页、分类、关键词搜索与详情通过。
- 实际发现父分类编号请求返回空列表，改为显示叶子分类后，分类请求复验通过。
- 非凡与量子的抽样视频 HLS 清单读取通过。暴风的抽样视频地址返回 HTTP 404，说明采集接口可用不保证媒体可用；应用保留错误提示、重试和换源入口。
